Quickstart & HTTP Polling Bridge Architecture

Setup

The 5500FP Setun 24 communicates bidirectionally between Retro Gadgets and the host workstation via an ultra-low latency HTTP polling queue.

💡
Zero-Configuration Bridge: The bridge runs a lightweight Node.js HTTP server on port 8080. The in-game Lua kernel polls /api/poll every second, ensuring non-blocking command execution without UDP packet loss.
STEP-BY-STEP WORKFLOW 
-- 1. In Retro Gadgets:
Open Multitool > Gadget View > Permissions > Check "Network Access".
Copy earth_os_kernel.lua into CPU0.lua and power on your gadget.

-- 2. In your terminal:
cd bridge && node bridge_server.js

-- 3. In your browser:
Navigate to http://localhost:8080 (5500FP Setun 24 Hardware Studio).
